Postman · codegen import용

Postman Collection

docs/postman/POLARIS_API.postman_collection.json

저장소에 포함된 컬렉션 파일 import

Postman 설정 방법

  1. Postman → Import → docs/postman/POLARIS_API.postman_collection.json 선택
  2. 또는 Import → Link → http://127.0.0.1:8000/openapi.json (서버 실행 중)
  3. Collection Variables에서 baseUrl을 환경에 맞게 수정 (예: http://10.0.2.2:8000)
  4. Supabase 세션의 access_token을 accessToken 변수에 설정
  5. Collection Auth는 Bearer Token → {{accessToken}} 사용

Swagger에서 인증 테스트

  1. 프론트/Supabase에서 access token 발급
  2. Swagger UI 우측 상단 Authorize 클릭
  3. Bearer {token} 형식으로 입력 (Bearer 접두사 포함)
FastAPI 기본 OpenAPI에는 Bearer scheme이 자동 등록되지 않을 수 있습니다. Swagger try-it-out 시 헤더를 직접 추가하거나 Postman 컬렉션 사용을 권장합니다.

5. 화면별 호출 흐름

앱 최초 진입 · 온보딩

  1. Supabase 세션 확인 → 없으면 signInAnonymously()
  2. GET /api/v1/me/onboarding — 완료 여부 확인
  3. 미완료: 북극성 입력 → POST /api/v1/onboarding/north-star/analyze
  4. 후보 선택 → PUT /api/v1/onboarding/north-star
  5. GET /api/v1/home 홈 진입

하루 기록 (별 생성)

  1. POST /api/v1/daily-records/analyze — AI 추출
  2. missing_questions 있으면 FE 고정 질문 UI 표시 후 태그 보완
  3. PUT /api/v1/daily-records/analyses/{id}/details — 태그 확정·재분류
  4. 주 성단 확인/수정 → POST .../confirm
  5. 홈 새로고침: GET /api/v1/home

혜성 · 은하

  1. 추천: POST /api/v1/comet-recommendations/generate → accept/reject
  2. 관측소: GET/POST /api/v1/comets, complete/cancel
  3. 은하 개요: GET /api/v1/galaxy/overview
  4. 계절 리포트: generate → 상세 → reflection 저장
